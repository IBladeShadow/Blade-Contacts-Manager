# Blade Contacts Manager

A simple contact manager CLI app written in Python.

## Features

- Add Contact
- Show Contacts
- Search Contact (by name, case-insensitive)
- Delete Contact (by name)
- Data saved to `contacts.json`

## Requirements

```
pip install colorama pyfiglet
```

## Run

```
python main.py
```

## Usage

```
Contact Manager
1. Add Contact
2. Show Contacts
3. Search Contact
4. Delete Contact
5. Exit
Choose:
```
